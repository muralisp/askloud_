Three Operational Modes for Complete Control

Choose the mode that fits your use case — from instant offline queries to autonomous infrastructure changes.

📸 Snapshot Mode

Instant, Offline Queries

  • Data: Local DynamoDB / JSON
  • Network: Zero (Offline)
  • Speed: <50ms
  • Context: Question + Schema

Perfect for demonstrations, demos with no network access, or schema exploration.

🔴 Live Mode

Real-Time Cloud APIs

  • Data: Real-time Cloud APIs
  • Network: Local CLI execution
  • Speed: API dependent
  • Context: Question only

Real-time visibility with full transparency into every command executed.

⚙️ Agentic Terraform

Safe Infrastructure Changes

  • Data: S3 tfstate & HCL
  • Network: Local Terraform
  • Speed: Awaits confirmation
  • Context: State + Diff

Render and deploy Terraform with full visibility before execution.

✅ Privacy First: In all modes, proprietary inventory data never leaves your local machine.

🔐 Agentic Terraform: Safe Change Architecture

The Agentic Change Flow includes:

  • Resolve: Lookup workspace, S3 tfstate, AWS profile
  • Read: Locate precise resource address in tfstate
  • Edit/Create: Patch .tf files or render HCL templates
  • Plan: Execute terraform plan with manual confirmation
  • Apply: Execute terraform apply -auto-approve

📊 Event-Driven Inventory Pipeline

Zero scheduled polling. Real-time accuracy via:

  • Terraform Apply → S3 tfstate triggers DynamoDB upsert
  • EC2 State Changes → EventBridge → Lambda → Queue
  • SHA-256 fingerprinting to prevent duplicate ingestion

LLM Safety & Efficiency Model

🔒 The Privacy Firewall

Your proprietary infrastructure data stays in your hands. Askloud sends only:

  • Natural language questions
  • Field schemas (not data)
  • Generic reference documentation

Never shared: Inventory data, cloud API responses, CLI outputs, or cloud credentials.

Quick Start: Deploy Locally in Seconds

Get Askloud running on your machine in three steps:

Prerequisites

  • Docker
  • Anthropic API key
  • Local cloud credentials (~/.aws, ~/.azure)

Deploy

# Set your Anthropic API key export ANTHROPIC_API_KEY=your_key_here # Run Askloud ./run_askloud.sh --live docker-compose up gui

✅ Web GUI available instantly at localhost:8000
✅ Cloud credentials (~/.aws, ~/.azure) mount automatically—read-only and secure
